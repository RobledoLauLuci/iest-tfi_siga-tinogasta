# 06 · Diseño UI: la marca en pantalla

Estética de galería de arte contemporánea: cálida, ordenada y con mucho aire. Las obras son las protagonistas.

## Pantallas
| Ruta | Pantalla |
|---|---|
| `/` | Inicio: portada, obras destacadas y talleres |
| `/galeria` | Galería con filtros por categoría |
| `/obra/:id` | Detalle de obra |
| `/talleres` | Lista de talleres e inscripción |
| `/contacto` | Formulario de contacto |
| `/login` y `/registro` | Acceso |
| `/panel` | Panel de artista o administradora |

## Aplicación de la identidad
| Elemento | Regla |
|---|---|
| Fondo | `--color-fondo` (crema) |
| Títulos | `--fuente-titulos`, `--color-texto` |
| Subtítulos | `--fuente-subtitulos` |
| Texto | `--fuente-texto`, `--color-texto` |
| Botón principal | Fondo `--color-principal`, texto negro |
| Tarjeta de obra | Fondo blanco, borde `--color-lienzo`, radio `--radio-borde` |
| Formularios | Borde `--color-lienzo`, foco con `--color-secundario` |
| Detalles | Líneas e íconos en `--color-dorado` |
| Estados | Disponible: verde agua; vendida: lila |

## Encabezado y logo
Logo principal en el encabezado, ícono `favicon-64.png` en la pestaña. Grilla de obras de 3 columnas en computadora, 2 en tableta y 1 en celular.
